# 📚 Inclusive Learning Platform

> An inclusive web-based learning platform designed to provide an accessible and user-friendly learning experience for students with different learning needs.

## 🌐 Live Demo

🚀 **[View Live Project](https://frontend-sigma-five-94.vercel.app/)**

## 📌 Project Overview

The **Inclusive Learning Platform** is a full-stack web application focused on making digital learning more accessible and inclusive.

The platform provides a structured learning environment where users can access educational content through a simple and responsive interface.

The project is developed using a separate **frontend and backend architecture**, making the application easier to maintain, extend, and deploy.

## ✨ Key Features

* 📖 Accessible learning interface
* 👩‍🎓 Student-focused learning experience
* 📱 Responsive web design
* 🔐 Backend API integration
* ⚡ Dynamic frontend
* 🗂️ Structured separation of frontend and backend
* 🌐 Deployed live for web access

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sowmya-kancharla03/Inclusive-Learning-platform.git
```

### 2. Navigate to the Project

```bash
cd Inclusive-Learning-platform
```

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend application will then run locally.

### 4. Setup Backend

Open another terminal:

```bash
cd backend
```

Install the required backend dependencies and start the backend server according to the backend configuration.
